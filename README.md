# Zhenrong Wang — research homepage

A static academic homepage built with HTML and CSS for GitHub Pages. No build step or JavaScript framework is required.

## Preview locally

Run `python3 -m http.server 8000` from this directory, then open `http://localhost:8000`.

## Update content

- Edit `index.html` to update the biography, research interests, publications, and contact links.
- Edit `stylesheet.css` for layout, colors, and responsive styles.
- Add publication images to `images/` and BibTeX files to `data/`.
- Before publishing, review `CNAME` and ensure that it contains the intended custom domain, or remove it if using the default GitHub Pages domain.
